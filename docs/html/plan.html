Buff — Project Plan

An AI-powered Chrome extension that reads a website's HTML/CSS and rewrites it to be modern, responsive, and mobile-friendly — using the user's own API key. No backend required.
Phase 2 of 7 complete. Next: Content + Background scripts.

Problem

Millions of websites — government, academic, local business — are desktop-only and visually frozen in the past. Their owners will never update them. Users have no recourse.

Solution

Click the extension. It sends the page structure to an AI model, receives improved CSS, and injects it into the live page. No CSS knowledge, no sign-up, no backend.

Design Principles

BYOK User supplies Anthropic or OpenAI key. Zero backend, zero cost to developer.
CSS only Never rewrite HTML. <style> injection is safe; DOM rewrites break JS listeners.
Non-destructive .buff-active class removal instantly restores original styles.
Per-site persistence CSS saved to chrome.storage by domain, auto-applied on return.
Progressive Large pages improved in slices across multiple runs; CSS merges additively.

How It Works

Four pure functions in lib/ transform data from DOM to injected CSS. Side effects are isolated: one AI call in background.ts, one DOM write in content.ts.

■ lib/ functions are pure — no browser APIs, fully testable in Node.  ■ background.ts owns the AI API call and storage writes.  ■ content.ts owns all DOM access.

Step 4 lib/extractPageStructure.ts

Strips text and media, keeps layout skeleton. Slices large pages into thirds for progressive improvement.

export interface PageSlice {
  htmlSkeleton: string; existingCSS: string;
  viewport: { width: number; height: number };
  url: string; sliceIndex: number; totalEstimatedSlices: number;
}

export function extractPageStructure(sliceIndex = 0): PageSlice {
  const clone = document.documentElement.cloneNode(true) as HTMLElement;

  // Strip text nodes, leaving only structure
  const walker = document.createTreeWalker(clone, NodeFilter.SHOW_TEXT);
  const texts: Node[] = [];
  while (walker.nextNode()) texts.push(walker.currentNode);
  texts.forEach(n => (n.textContent = ''));
  clone.querySelectorAll('script,noscript,svg,img,video,iframe').forEach(el => el.remove());

  const all = Array.from(clone.querySelectorAll('body>*,main>*,article>*'));
  const size = Math.ceil(all.length / 3);
  const htmlSkeleton = all.slice(sliceIndex * size, (sliceIndex + 1) * size)
    .map(el => el.outerHTML).join('\n').substring(0, 15000);

  const layout = ['width','display','float','grid','flex','position','margin','padding'];
  const rules = Array.from(document.styleSheets)
    .filter(s => !s.href || s.href.startsWith(location.origin))
    .flatMap(s => { try { return Array.from(s.cssRules).map(r => r.cssText); } catch { return []; } });
  const existingCSS = [
    ...rules.filter(r => layout.some(k => r.includes(k))),
    ...rules.filter(r => !layout.some(k => r.includes(k)))
  ].join('\n').substring(0, 10000);

  return { htmlSkeleton, existingCSS, sliceIndex, url: location.hostname,
    totalEstimatedSlices: Math.max(1, Math.ceil(all.length / size)),
    viewport: { width: window.innerWidth, height: window.innerHeight } };
}
Step 5 lib/buildPrompt.ts

Scopes all generated selectors under .buff-active — high specificity without !important spam.

import type { PageSlice } from './extractPageStructure';

export function buildPrompt(pageData: PageSlice, userHint?: string): string {
  const note = pageData.totalEstimatedSlices > 1
    ? `Section \${pageData.sliceIndex + 1} of ~\${pageData.totalEstimatedSlices}.` : '';
  return `You are an expert CSS developer. Return ONLY valid CSS.
Prefix ALL selectors with .buff-active. No *, no @import, no position:fixed.
\${note}\${userHint ? \`User requested: "\${userHint}"\` : ''}
PAGE DATA: \${JSON.stringify(pageData)}\`;
}
Step 6 lib/sanitizeCSS.ts

Blocks dangerous values, not whole properties — the AI still needs position to work correctly.

export function sanitizeCSS(raw: string): string {
  return raw
    .replace(/\*\s*\{[^}]*\}/g, '')
    .replace(/@import[^;]+;/gi, '')
    .replace(/position\s*:\s*(fixed|absolute)\s*;/gi, '')
    .replace(/(?<!\S)(width|height)\s*:\s*\d+px\s*;/gi, '')
    .replace(/display\s*:\s*none\s*;/gi, '')
    .replace(/z-index\s*:\s*(\d+)\s*;/gi, (m, v) => +v > 999 ? '' : m)
    .trim();
}
Step 7 lib/apiClient.ts 
import Anthropic from '@anthropic-ai/sdk';
import OpenAI    from 'openai';
export type Provider = 'anthropic' | 'openai';

const unfence = (s: string) =>
  s.match(/```(?:css)?\s*([\s\S]*?)```/)?.[1].trim() ?? s.trim();

export async function generateCSS(
  prompt: string, apiKey: string, provider: Provider, model: string
): Promise<string> {
  if (provider === 'anthropic') {
    const msg = await new Anthropic({ apiKey, dangerouslyAllowBrowser: true })
      .messages.create({ model, max_tokens: 4096,
        messages: [{ role: 'user', content: prompt }] });
    return unfence((msg.content[0] as any).text);
  }
  const res = await new OpenAI({ apiKey, dangerouslyAllowBrowser: true })
    .chat.completions.create({ model, max_tokens: 4096,
      messages: [{ role: 'user', content: prompt }] });
  return unfence(res.choices[0].message.content ?? '');
}

export async function validateAnthropicKey(apiKey: string) {
  try { await new Anthropic({ apiKey, dangerouslyAllowBrowser: true }).models.list(); return true; }
  catch { return false; }
}
export async function validateOpenAIKey(apiKey: string) {
  try { await new OpenAI({ apiKey, dangerouslyAllowBrowser: true }).models.list(); return true; }
  catch { return false; }
}
Step 8 Content Script (entrypoints/content.ts) 
const ID = 'buff-injected-styles';
const host = location.hostname;

export function injectCSS(css: string) {
  document.getElementById(ID)?.remove();
  Object.assign(document.createElement('style'), { id: ID, textContent: css });
  document.head.appendChild(document.getElementById(ID)!);  // see full source
  document.documentElement.classList.add('buff-active');
  chrome.storage.local.set({ [`active:\${host}`]: true });
}

chrome.storage.local.get([`css:\${host}`, `autoApply:\${host}`], r => {
  if (r[`css:\${host}`] && r[`autoApply:\${host}`] !== false) injectCSS(r[`css:\${host}`]);
});

chrome.runtime.onMessage.addListener((msg, _, send) => {
  if (msg.type === 'GET_PAGE_STRUCTURE') send({ structure: extractPageStructure(msg.sliceIndex??0) });
  if (msg.type === 'INJECT_CSS') { injectCSS(sanitizeCSS(msg.css)); send({ success:true }); }
  if (msg.type === 'RESET_CSS')  { removeInjectedCSS(); send({ success:true }); }
  return true;
});
Step 9 Background Worker (entrypoints/background.ts) 
chrome.runtime.onMessage.addListener((msg, _, send) => {
  if (msg.type !== 'IMPROVE_PAGE') return;
  (async () => {
    const { apiKey, provider, model } = await getSettings();
    if (!apiKey) { send({ error: 'No API key. Open extension settings.' }); return; }
    const cached = await getStoredCSS(msg.domain);
    if (cached && !msg.forceRegenerate && msg.sliceIndex === 0) {
      send({ css: cached, fromCache: true }); return;
    }
    const newCSS  = await generateCSS(buildPrompt(msg.pageStructure, msg.userHint), apiKey, provider, model);
    const merged  = msg.sliceIndex > 0 && cached
      ? `\${cached}\n\n/* Slice \${msg.sliceIndex} */\n\${newCSS}` : newCSS;
    await storeCSS(msg.domain, merged);
    send({ css: merged, fromCache: false });
  })();
  return true;
});
Step 10 Storage Helpers (lib/storage.ts) 
export interface Settings { apiKey:string; provider:'anthropic'|'openai'; model:string }

const g = (k:string[]) => new Promise<any>(r => chrome.storage.local.get(k,r));
const s = (o:object)   => new Promise<void>(r => chrome.storage.local.set(o,r));

export async function getSettings(): Promise<Settings> {
  const r = await g(['apiKey','provider','model']);
  return { apiKey:r.apiKey??'', provider:r.provider??'anthropic', model:r.model??'claude-sonnet-4-6' };
}
export const saveSettings  = (x:Partial<Settings>) => s(x);
export async function getStoredCSS(d:string) {
  const r = await g([`css:\${d}`]); return r[`css:\${d}`]??null;
}
export const storeCSS = (d:string, css:string) => s({[`css:\${d}`]:css});
export const clearCSS = (d:string) =>
  new Promise<void>(r => chrome.storage.local.remove([`css:\${d}`,`active:\${d}`,`autoApply:\${d}`],r));
export async function getAllSavedDomains() {
  const r = await g(null as any);
  return Object.keys(r).filter(k => k.startsWith('css:')).map(k => k.slice(4));
}

Known Risks & Mitigations

RiskMitigation
Page HTML too large for context window Layout CSS prioritised, above-fold first. Slice-based progressive improvement for large pages.
Injected CSS breaks page layout Value-aware sanitizer (blocks dangerous values, not properties). Instant reset via .buff-active class removal.
JS-driven styles fighting injected CSS All AI selectors scoped under .buff-active on <html> — high specificity, no !important.
CSP headers blocking style injection Use chrome.scripting.insertCSS() which bypasses page-level CSP.
API key exposed in storage Stored in chrome.storage.local (not synced). Options page notes key stays on-device.
Chrome Web Store review for <all_urls> Extension activates only on explicit click; reads no personal data. Documented justification ready.
AI returns markdown-fenced CSS unfence() in apiClient.ts strips fences silently before returning.
Shadow DOM content not styled Documented limitation. UI notes that embedded widgets may be unaffected.
High per-call API cost Default Sonnet ~$0.08/call. Haiku option ~$0.02/call for cost-conscious users.
